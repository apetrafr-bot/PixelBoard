Propriétaire : activer les comptes sur Hostinger

Publiez tout le contenu de dist, y compris api. Dans pixelboard-config.php, à côté de public_html, renseignez la base MySQL et le secret privé à partir de api/config.example.php. Importez api/schema.sql via phpMyAdmin seulement pour une base vide.
